# 权限与权限配置系统

本文档说明如何使用权限和权限配置管理模块。

## 功能概述

权限管理系统提供以下主要功能：

### 1. 用户组管理
- **创建用户组** - 为团队创建不同的用户组（如 Product、Engineering、Design等）
- **查看用户组列表** - 浏览系统中所有的用户组
- **编辑用户组** - 修改用户组信息
- **删除用户组** - 删除不再需要的用户组

### 2. 用户搜索
- **按用户名搜索** - 根据用户名查找用户
- **按邮箱搜索** - 根据邮箱地址查找用户
- **查看用户详情** - 了解用户的完整信息
- **自定义搜索范围** - 设置返回的用户数量

### 3. 我的权限
- **查看个人权限** - 了解当前用户拥有的权限
- **查看所属用户组** - 查看当前用户加入的所有用户组
- **了解权限系统** - 学习系统的权限等级和规则

### 4. Wiki权限管理
- **查看Wiki页面列表** - 浏览所有Wiki页面及其权限配置
- **编辑页面权限** - 为Wiki页面设置读写权限
- **配置用户组权限** - 为特定用户组分配页面访问权限
- **配置个人权限** - 为特定用户分配页面访问权限

## 页面访问路径

```
/admin/permissions
```

侧边栏导航菜单中可以找到"权限管理"选项。

## 权限等级说明

### 超级管理员 (is_superuser)
- 拥有系统中的所有权限
- 可以创建和删除用户组
- 可以管理所有Wiki页面的权限
- 可以查看所有用户信息

### 员工权限 (is_staff)
- 可以创建用户组
- 可以根据组权限管理Wiki页面
- 可以查看所有用户信息

### VIP用户 (is_vip)
- 享受高级功能
- 获得优先级支持

### 普通用户
- 可以创建和编辑自己的Wiki页面
- 可以根据权限访问他人的页面

## 权限检查流程

权限系统按以下优先级检查：

1. **超级管理员/staff** - 拥有所有权限
2. **创建者** - 对自己创建的页面有永久编辑权
3. **显式授权** - 通过WikiPermission配置的权限

## Wiki页面权限管理

### 权限类型

#### 读取权限 (read)
控制哪些用户可以查看页面内容。

#### 编辑权限 (edit)
控制哪些用户可以修改页面内容。

### 权限格式

页面权限可以设置为以下格式：

```json
{
  "permissions": {
    "read": ["all"],
    "edit": ["team-Product", "john_doe"]
  }
}
```

| 格式 | 说明 | 示例 |
|------|------|------|
| `"all"` | 所有已认证用户 | `"read": ["all"]` |
| `"team-组名"` | 特定用户组 | `"edit": ["team-Product"]` |
| `"用户名"` | 特定用户 | `"edit": ["john_doe"]` |

### 权限配置示例

#### 示例1：公开可读，仅创建者可编辑
```json
{
  "permissions": {
    "read": ["all"],
    "edit": []
  }
}
```
任何人都可以读取，但只有创建者可以编辑。

#### 示例2：团队协作
```json
{
  "permissions": {
    "read": ["team-Product", "team-Engineering"],
    "edit": ["team-Product"]
  }
}
```
Product和Engineering两个团队都可以读取，但只有Product团队可以编辑。

#### 示例3：私密文档
```json
{
  "permissions": {
    "read": ["alice", "bob"],
    "edit": ["alice"]
  }
}
```
只有alice和bob可以读取，只有alice可以编辑。

#### 示例4：开放编辑
```json
{
  "permissions": {
    "read": ["all"],
    "edit": ["all"]
  }
}
```
所有人都可以读取和编辑（谨慎使用）。

## 用户组管理工作流程

### 1. 创建用户组

1. 进入权限管理页面
2. 点击"用户组管理"标签
3. 点击"创建用户组"按钮
4. 输入用户组名称
5. 点击"创建"

**API端点**：`POST /api/auth/groups/`

```bash
curl -X POST http://example.com/api/auth/groups/ \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "name": "Design"
  }'
```

### 2. 查看用户组列表

1. 进入权限管理页面
2. 点击"用户组管理"标签
3. 查看所有用户组卡片

**API端点**：`GET /api/auth/groups/`

```bash
curl -X GET http://example.com/api/auth/groups/ \
  -H "Authorization: Bearer <token>"
```

## 用户搜索工作流程

### 1. 搜索用户

1. 进入权限管理页面
2. 点击"用户搜索"标签
3. 输入用户名或邮箱地址
4. 点击"搜索"或按Enter键
5. 查看搜索结果

**API端点**：`GET /api/auth/users/search/`

```bash
curl -X GET "http://example.com/api/auth/users/search/?query=john&limit=10" \
  -H "Authorization: Bearer <token>"
```

### 2. 查看用户详情

1. 在搜索结果中点击"查看详情"
2. 查看用户的完整信息

## Wiki权限管理工作流程

### 1. 编辑Wiki页面权限

1. 进入权限管理页面
2. 点击"Wiki权限管理"标签
3. 找到需要编辑的页面
4. 点击"编辑权限"按钮
5. 修改读取和编辑权限
6. 点击"保存权限"

### 2. 设置用户组访问权限

1. 打开页面的权限编辑对话框
2. 在"可读权限"或"可编辑权限"部分
3. 选择要添加权限的用户组
4. 点击"保存权限"

### 3. 设置特定用户访问权限

1. 打开页面的权限编辑对话框
2. 在"可读权限"或"可编辑权限"部分
3. 输入用户名并按Enter键添加
4. 点击"保存权限"

## 我的权限信息

1. 进入权限管理页面
2. 点击"我的权限"标签
3. 查看以下信息：
   - **用户信息** - 用户名、邮箱、账户状态
   - **权限管理** - 权限标志、所属用户组
   - **权限详情说明** - 不同权限等级的说明

## 常见问题

### Q: 如何为用户组分配权限？

A: 权限是在Wiki页面级别上配置的。创建用户组后，可以在编辑Wiki页面权限时为该用户组分配页面的读取或编辑权限。

### Q: 如何删除用户组？

A: 在用户组卡片的菜单中选择"删除"，确认后即可删除。

### Q: 权限更新后需要多长时间生效？

A: 权限更新立即生效。用户刷新页面后即可看到新的权限设置。

### Q: 如何恢复删除的用户组？

A: 删除操作无法撤销。需要重新创建用户组。

### Q: 是否可以修改用户的权限等级？

A: 超级管理员和员工权限需要通过Django Admin后台修改。普通用户只能通过Wiki页面权限来控制访问。

## 最佳实践

### 1. 用户组命名约定
```
ProductTeam - 产品团队
EngineeringTeam - 工程团队
DesignTeam - 设计团队
```

### 2. 权限配置原则
- **最小权限原则** - 只授予必要的权限
- **定期审查** - 定期检查和更新权限设置
- **文档化** - 记录为什么要分配某些权限

### 3. Wiki页面权限设置
- 公开内容 - 使用 `read: ["all"]`
- 内部文档 - 使用特定用户组或用户
- 个人笔记 - 只为自己和必要的人分配权限

### API调用
权限管理系统通过以下API进行通信：

| 功能 | 端点 | 方法 | 权限要求 |
|------|------|------|----------|
| 获取用户组列表 | `/api/auth/groups/` | GET | 已认证 |
